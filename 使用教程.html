2第一步：搜索一本书

网站提供 三种搜索模式，点击 Tab 切换：

模式 1：智能搜索（最常用）

一个输入框搞定一切，系统自动识别你输入的是书名、作者还是 ISBN：

  • 输入 算法导论 → 按书名搜索
  • 输入 周志华 → 按作者搜索
  • 输入 9787111407010 → 按 ISBN 精确查询

自动补全：输入 2 个字符后，搜索框下方会弹出实时建议列表。 用 ↑ ↓ 选择建议，Enter 确认，Esc 关闭，鼠标点击任意建议直接搜索。

小技巧：试试搜索框下方的快捷示例标签（如「人类简史 赫拉利」），点一下即可体验完整流程。

模式 2：ISBN 精确查询

已知 ISBN 时使用。支持 10 位或 13 位，带横线也可以（如 7-111-40701-6），系统会自动校验格式并互转。

模式 3：高级组合查询

书太热门、重名太多时使用。分别填写 书名 / 作者 / 版次 任意组合，填一个即可，填得越多越精准。

3第二步：确认目标书籍

用书名/作者搜索时，通常会匹配到多本书（不同版次、不同出版社、不同译本）。网站会展示 候选书籍列表：

│ 书名      │ │ 书名      │ │ 书名      │
│ 作者/出版社│ │ 作者/出版社│ │ 作者/出版社│
│ 版次+ISBN │ │ 版次+ISBN │ │ 版次+ISBN │

└──────────┘ └──────────┘ └──────────┘
     桌面 3 列 / 平板 2 列 / 手机 1 列

怎么选：

  • 鼠标点击卡片任意位置或「选择这本书」按钮
  • 键盘↑ ↓ 在卡片间移动（高亮项带绿色描边），Enter 确认
  • 折叠超过 6 本时列表自动折叠，点「展开其余 N 本」查看全部
为什么要人工确认？「算法导论 第3版」和「第4版」是两本不同的书，价格不可比。这一步帮你锁定唯一版本（以 ISBN-13 为准）。

5价格趋势图

结果面板最下方是 历史价格折线图（Recharts 渲染）：

  • 横轴 = 时间，纵轴 = 价格（元）；每个平台一条固定颜色的线
  • 点击图例可显示/隐藏对应平台（再点一次恢复）
  • 鼠标悬停图表可查看该时间点各平台的具体价格
数据从哪来？每次搜索自动记录到本地 SQLite。首次查询会提示「暂无历史数据」——同一本书多查几遍、隔几天再查，折线就会逐渐长出来，即可看出价格走势与最稳定的低价平台。

6暗色模式与快捷键

点顶部导航栏右侧的 🌙 图标切换深色主题（背景 #1a1d1a），偏好会被记住。

按键位置作用
↑ ↓搜索框选择自动补全建议
↑ ↓候选列表在候选书籍间移动高亮
Enter搜索框搜索（或确认选中的建议）
Enter候选列表确认高亮的书并开始比价
Esc搜索框关闭补全下拉

移动端：手机浏览器打开即用——卡片自动单列、搜索栏占满宽度、触点加大单手可操作。

7常见问题

问题原因与解决办法
「ISBN 格式不正确」校验位不合法，核对数字；10/13 位均支持，可带横线
「未找到匹配书籍」换个关键词：书名+作者、去掉副标题、或直接用 ISBN
「该候选书籍缺少 ISBN」该版本无 ISBN 记录（常见于极老的书），请选其他版本
某平台「暂时不可用」平台超时/限流或未配置密钥，稍后重试，其他平台不受影响
趋势图「暂无历史数据」正常现象，同一本书多搜索几次后自动积累
想重新搜别的书直接在顶部搜索框输入新内容，结果区自动刷新
价格数据仅供参考，以平台实际结算为准 · 跳转链接均指向平台官方站点
